# Chatium processes skill

Этот репозиторий — единственный исходник скилла `processes`. Здесь его
разрабатывают; установленные копии в аккаунтах Chatium не являются отдельными
источниками правок. Позже скилл переедет в `chatium-agent-skills` рядом с
`chatium-development`.

Для установки в Git-аккаунт Chatium агент получает этот репозиторий во
временную папку, копирует содержимое **без `.git` и `node_modules`** в
`.agents/skills/processes/`, затем коммитит и публикует файлы скилла вместе
с кодом аккаунта. Папка должна отслеживаться Git аккаунта: тогда она
появится и в новой рабочей среде другого человека. Зависимости устанавливаются
в аккаунте командой `npm ci --ignore-scripts` из папки скилла.

Обновление делается **по просьбе пользователя**: агент получает актуальную
версию этого репозитория, переносит изменения в отслеживаемую папку аккаунта
(включая удаления), проверяет разницу и совместимость, затем коммитит и
публикует обновление аккаунта. Обычный `git pull` аккаунта после этого
доставит скилл в новые рабочие среды. Не обновляй его автоматически перед
каждой задачей.

В аккаунте также должен быть скилл `chatium-development`. Требования к
окружению и доступу к Chatium описаны в [build/environment.md](build/environment.md).

Исходник для установки — опубликованная версия `main` или выбранный тег.
Локальные незакоммиченные правки в этом репозитории не входят в такую версию.
