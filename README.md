# Chatium processes skill — development source

Здесь разрабатывается и проверяется `chatium-processes`. Рабочие инструкции
агента — [SKILL.md](SKILL.md). Production-копия поставляется из
`skills/chatium-processes` репозитория `chatium/chatium-agent-skills`.
Публикация этого исходного репозитория сама по себе не обновляет клиентов.

## Разработка и проверка

Меняй исходник здесь, запускай `npm test`, проверяй diff и фиксируй версию.
Для испытания зафиксированного локального кандидата по поручению владельца:

```sh
node .github/sync-skill.mjs install-local '/путь/к/Git-аккаунту'
```

Команда устанавливает кандидата в игнорируемую Git папку
`.agents/skills/chatium-processes`, ставит зависимости и записывает
`INSTALLATION.json` с `localCandidate: true`. Это локальное испытание:
штатное обновление CLI заменит кандидата production-версией.

## Выпуск

Изменение production-копии — релиз, требующий явного поручения владельца.
После проверок и коммита выполни из исходного репозитория:

```sh
node .github/sync-skill.mjs release '../chatium-agent-skills'
node .github/sync-skill.mjs release-status '../chatium-agent-skills'
```

Команда берёт только зафиксированный HEAD, переносит рабочие инструкции,
каталоги, скрипты, схемы, шаблоны, лицензию и npm-зависимости, включая удаления.
Она исключает Git, CI, локальные документы, тесты, node_modules, корневой
README и настройки разработки. Из runtime package.json удаляется команда
тестов исходника. Содержимое сверяется по SHA-256. Незафиксированные изменения
исходника или самой production-копии останавливают запись.

Проверь diff в `chatium-agent-skills`, затем зафиксируй релиз; публикация его
main делает новую копию доступной клиентам. Не разрабатывай прямо в папке
поставки и не копируй туда рабочий каталог целиком. Точная версия выпуска —
коммит исходника и SHA-256, выданные командой; npm version не является номером
релиза скилла.

## Установка клиентом

Из корня аккаунта: `chatium get-skills`. CLI обновляет `chatium-processes` и
`chatium-development` в `.agents/skills/` и `.claude/skills/`. Эти папки не
коммитятся в Git аккаунта и могут быть заменены следующим обновлением.
Окружение и зависимости — [build/environment.md](build/environment.md).
