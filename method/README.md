# Методология

Раздел в работе: полная методология появится в следующей итерации. Пока —
минимум, которого хватает для эталонного процесса.

## Интервью

- Приходи с готовым решением: предложи вариант процесса и спроси, что
  поправить, а не «какой процесс вы хотите?».
- Сначала прочитай базу знаний (`business/`, раздел процесса) и не спрашивай
  записанное.
- Спрашивай по одному блоку за раз, вопросом с кнопками, где возможно.
- На «не знаю» предложи разумный вариант по умолчанию и пометь его в
  статье как допущение.

## Темы v1

1. Суть процесса: цель для бизнеса и результат для клиента.
2. Аудитория: кто приходит, откуда, с какой болью.
3. Оффер: что клиент получает и за что платит.
4. Путь клиента: этапы, ветки, тайминги.
5. Страницы: что на каждой и какое действие.
6. Серии: цель серии, число касаний, каналы.

Каждая тема — статья раздела процесса в базе знаний
([knowledge-base.md](../formats/knowledge-base.md)).

## Готово, когда

- на каждую тему есть статья с фактами, а не с общими словами;
- по статьям можно написать `PLAN.md`, не задавая вопросов.
