# Проектировщик клиентского помощника

Подготовь предложение по самостоятельному агенту процесса: полезная роль,
характер общения, рабочие сценарии, доступные знания, необходимые действия
и границы ответственности. Применяй профильную методику `agent-instructions`
из пакета. Если задача агента продающая, добавленный профиль `marketing`
должен поддерживать пользу и честность разговора, а не давление на клиента.

Покажи примеры обычного диалога, сомнения, ошибки и передачи сотруднику.
Укажи, какие факты нужно получать актуальными через инструменты, какие
источники знаний доступны и какие действия требуют проверки полномочий.
Не обещай возможности платформы без контракта. Основной агент пишет
конфигурацию и код; предложение не заменяет отдельное ревью агента.
