# Ревью самостоятельных помощников

После сборки принятой ИИ-роли и до живого теста проведи отдельное смысловое ревью. Общий code-review проверяет безопасность и соответствие плана коду; здесь независимый reviewer проверяет качество инструкций, фактические знания, действия, маршрут, передачу и сценарии. Этот шаг не запускается автоматически от изменения файла.

```sh
node .agents/skills/processes/scripts/agent-review.mjs prepare <process>
```

Команда создаёт `packet.json`, `prompt.md` и неизменяемый снимок справок вне аккаунта. Передай содержимое `prompt.md` отдельному субагенту с чистым контекстом через инструмент своего окружения. Он читает два входных `SKILL.md`, обязательные разделы из `referenceLibrary.required`, затем нужные справки и typings выборочно. Пакет включает фактические инструкции, локальный код, знания, план и сценарии; не редактируй исходники до ответа.

Сохрани полный JSON-ответ ревьюера в файл вне аккаунта и запиши результат:

```sh
node .agents/skills/processes/scripts/agent-review.mjs record <process> \
  --packet <путь-к-пакету>/packet.json --report <путь-к-ответу>.json --agent <ID-вызова>
node .agents/skills/processes/scripts/agent-review.mjs status <process>
```

Скрипт проверяет полный ответ и цитаты, хеш входных материалов и справок, принадлежность отчёта независимому вызову. Устаревший отчёт, отсутствующий ответ или блокер не дают считать роль готовой к тесту. После исправления снова подготовь пакет и повтори ревью. Общий `check --task-stage test|launch` отдельно требует записанную проверку опубликованных конфигов и маршрутов через `agents-runtime.mjs --record`; живой прогон эффектов остаётся отдельным действием по [карточке помощника](../blocks/ai-agent.md).
