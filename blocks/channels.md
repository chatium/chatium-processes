# Компонент: каналы и настройки процесса

**Для бизнеса.** Через что процесс говорит с клиентом (email, Telegram) и
какие значения владелец может поменять без разработчика: цена, адрес,
ссылки, сроки акции.

## Контракт

`<process>/.workspace.json`:

```json
{
  "type": "process",
  "config": {
    "senderChannels": [],
    "variables": {
      "trial_price": { "value": "500 ₽", "description": "Цена пробной тренировки" },
      "studio_address": { "value": "ул. Примерная, 1", "description": "Адрес студии" }
    }
  }
}
```

- `senderChannels` — ID конкретных каналов Sender, через которые шлёт
  процесс, а не названия транспортов вроде `email` или `telegram`.
  Агент получает подключённые каналы через `getChannels(ctx)` из `@sender/sdk`
  и записывает выбранные для процесса ID в это поле (`chatium exec`,
  `chatium-development/references/sender/entities.md`). Не выбирай все каналы
  аккаунта автоматически. Каналы подключает владелец в Sender
  (`/app/sender/v2#/settings/channel/add`). Если они ещё не подключены,
  оставь список пустым и добавь пункт «Нужно от вас», продолжая сборку.
  `check` показывает предупреждение, а не блокер. Перед тестовой отправкой
  заполни список и проверь доступность каналов. Пустой список в текущем
  Sender не запрещает отправку — он снимает ограничение по каналам.
- Выбор контактов, их приоритет и доставка по каналам — ответственность
  Sender. Не реализуй свою цепочку транспортов в каждом процессе.
- `variables` — значения процесса. В коде:
  `(await getWorkspaceConfig(ctx)).variables?.<key>?.value`. Функция берёт
  конфиг ближайшего воркспейса, то есть процесса.
- Меняет этот файл только агент. Если значение должен менять владелец в
  интерфейсе, храни его в Heap-таблице процесса.

## Как проверить

- `check`: `.workspace.json` разбирается, `type: process`; каждая
  переменная процесса, на которую ссылается код через `variables.<key>`,
  объявлена. Отсутствующий, пустой или некорректный `config.senderChannels`
  даёт предупреждение и сам по себе не делает проверку красной.
- Каналы: `getChannels(ctx)` в `chatium exec` — нужный канал активен.

## Грабли

- Дочерний `.workspace.json` внутри процесса отрежет папку от процесса:
  `getWorkspaceConfig` и события начнут работать от неё.
